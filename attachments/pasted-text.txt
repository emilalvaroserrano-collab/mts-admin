Admin Portal MVP Acceptance Criteria

- [ ] Admin can securely log in
- [ ] Admin can view and manage permitted Zendesk tickets
- [ ] Customer organizations and user permissions work correctly
- [ ] Admin can create and update equipment products
- [ ] Admin can view customer equipment orders
- [ ] Equipment orders are linked to Zendesk tickets
- [ ] Order PDFs can be viewed
- [ ] Changes and access respect company boundaries
- [ ] Admin Portal is accessible on Vercel staging

Implementation principle: Zendesk remains the source of truth for support tickets. Neon stores portal-specific data such as accounts, permissions, products, and orders. The Admin Portal brings those functions into one management interface.
